# ReefProof v0.1.0

ReefProof v0.1.0 was the first public release of the offline configuration-
assurance workbench for living systems.

> **Superseded:** Do not deploy this version for browser Workbench use. The
> published v0.1.0 OCI image omitted the Workbench JavaScript bundle, leaving
> the page visible but non-interactive. Use the
> [v0.1.1 hotfix](https://github.com/bobbravo2/ReefProof/releases/tag/v0.1.1).

## What changed

- Introduced deterministic, offline configuration snapshots and typed
  reliability graphs from bundled synthetic or operator-supplied evidence.
- Added invariant evaluation with explicit `PASS`, `FAIL`, and `UNKNOWN`
  outcomes plus persisted evaluation runs and findings.
- Added the attached-terminal CLI and commands for snapshots, graphs, checks,
  explanations, HYDROS export verification, and bounded database administration.
- Added an authenticated browser Workbench for manual return-flow policy review,
  Evidence, operator sessions, system status, and query-only database inspection.
- Added versioned `/v1` APIs, request correlation, structured mutation auditing,
  bounded metrics, authenticator-app enrollment, and session revocation.
- Added explicit local-managed and private-LAN remote-hosted modes with bounded
  diagnostics, restart, and one-time SQLite backup download operations.
- Published the first Linux amd64 OCI image with an SPDX SBOM, vulnerability
  report, immutable digest, and signed registry attestations.

## Who should use this release

Keep v0.1.0 only when reproducing historical release evidence. New deployments
and existing v0.1.0 installations should use v0.1.1 instead. The v0.1.1 hotfix
does not change the database schema, so the existing `/var/lib/reefproof` data
mount can be preserved during the image replacement.

## Known issue

The published container does not serve `/assets/workbench.js`; browser forms can
therefore fall back to native submission. Avoid submitting credentials through
the v0.1.0 Workbench and upgrade to v0.1.1.

## Safety boundary

ReefProof v0.1.0 is offline configuration assurance. HYDROS remains runtime
authority: ReefProof does not connect to HYDROS, publish MQTT messages, control
equipment, or perform automatic remediation.
