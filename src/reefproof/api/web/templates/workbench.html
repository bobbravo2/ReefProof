            01
            
            Secret stays out of evidence
            
            
            
              The bootstrap shared secret is submitted only to establish a local session
              before authenticator app enrollment.
              Immutable revisions record the opaque session identifier, never the secret.
            
            
          
            
          
            
            02
            
            Session stays process-local
            
            
            
              Restarting the service ends the session. A new authenticated session
              is required before another policy revision can be authored.
            
            
          
            
          
            
            03
            
            Authority stays bounded
            
            
            
              A session can author ReefProof-owned local evidence. It cannot mutate
              HYDROS, publish MQTT messages, or remediate the living system.
